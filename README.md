# Task-03: Tic-Tac-Toe Web Application

🎮 Developed an interactive Tic-Tac-Toe game using HTML, CSS, and JavaScript for my internship at Prodigy InfoTech.

## ✨ Features:

- **2-player turn-based gameplay** with visual indicators
- **Score tracking** for multiple games
- **Winning line highlighting** with animations
- **Responsive design** that works on all devices
- **Professional UI** with gradient backgrounds and glassmorphism
- **Smooth animations** and hover effects
- **Keyboard shortcuts** for quick access
- **Game state management** with restart and score reset

## 🎮 Controls:

- **Click cells** to place X or O
- **Restart Game** button to start a new game
- **Reset Score** button to clear all scores
- **Keyboard shortcuts:**
  - **Ctrl/Cmd + R** - Restart game
  - **Ctrl/Cmd + S** - Reset score

## 🚀 How to Play:

1. Open the game in your web browser
2. Player X goes first (red)
3. Click any empty cell to place your mark
4. Player O goes next (blue)
5. Get three in a row to win!
6. Use the buttons to restart or reset scores
